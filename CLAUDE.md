# Click the Circle — пам'ятка для Claude

Власник — учитель української, не програміст. Усе робить Claude: пояснюй простою мовою, відповідай українською.

## Що це
Маленька тестова гра (2025): клікаєш по колу, що стрибає полем, — набираєш бали. Один файл `index.html` (HTML + CSS + JS разом), без бібліотек і без збирання. Автоматичного викладання на сервер немає.

## Правила роботи
- Гра невелика — можна тримати все в одному `index.html`. Якщо вона розростеться понад ~1000 рядків, винеси JS у `script.js`, а CSS у `style.css`.
- Основні мовні ігри — в репозиторії ukrmovych/naholosy; нові навчальні ігри краще робити там.
